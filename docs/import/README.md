# Як завантажити товари в бота

Інструкція для власника або менеджера магазину. Усе робиться в чаті
менеджерів у Telegram — тому, ID якого записано в `ADMIN_CHAT_ID`.
Нічого не треба налаштовувати на сервері.

## Коротко

1. Вивантажте товари у файл Excel (`.xlsx`) або CSV — з 1С, BAS чи від
   постачальника.
2. Надішліть файл у чат менеджерів. Підпис не потрібен.
3. Перший раз бот покаже, як він прочитав колонки. Перевірте й дайте
   постачальнику назву.
4. Бот покаже звіт: скільки товарів додасться, оновиться, зніметься з
   продажу. Натисніть **«✅ Застосувати»**.

Далі надсилайте свіжі файли так само. Бот сам упізнає постачальника, і
звіт з'явиться одразу.

## Який потрібен файл

Таблиця, де кожен рядок — товар, а зверху — рядок із назвами колонок.
Над ним можуть бути назва звіту, дата, порожні рядки: бот їх пропустить.

| Колонка | Обов'язкова? | Навіщо |
|---|---|---|
| Назва | так | що бачить покупець |
| Ціна | так | ціна продажу (або закупівельна — тоді вкажете націнку) |
| Код товару **або** Артикул | хоча б одна | за нею наступний файл знаходить товар і оновлює його, а не створює ще раз |
| Залишок | бажано | без неї всі товари будуть «під замовлення» |
| Бренд | бажано | покупці часто шукають за брендом; фото й аналоги з каталогу Auto-DB знаходяться здебільшого за артикулом разом із брендом |
| Група | бажано | група з 1С допомагає розкласти товари по категоріях |
| Авто, Роки авто, Де на авто | ні | до яких машин підходить деталь |
| Фото, Опис | ні | |

Назви колонок можуть бути будь-якими: «Номенклатура», «Найменування»,
«Цена», «Ціна роздріб, грн», «Остаток», «Наявність» — бот розуміє
українські й російські варіанти, зокрема ті, що дає 1С.

Формат — `.xlsx` або `.csv`, до 20 МБ. Старий `.xls` бот не читає: відкрийте
його в Excel і збережіть як «Книга Excel (.xlsx)».

### Як вивантажити з 1С або BAS

Підійде будь-який звіт чи список номенклатури, де є код, назва, ціна і
залишок (наприклад, прайс-лист або залишки товарів з цінами). Сформуйте
його і збережіть через **Файл → Зберегти як**, тип — «Лист Excel 2007-...
(*.xlsx)». Назви меню відрізняються між версіями 1С і BAS; якщо не
знаходите потрібний звіт, попросіть програміста 1С зробити вивантаження з
колонками з таблиці вище.

Вивантажуйте щоразу той самий звіт з тими самими колонками: тоді бот
упізнає файл без питань.

## Перший файл постачальника

Бот показує, яку колонку для чого він узяв:

```
📄 export.xlsx — новий для мене файл.

✅ Назва: «Номенклатура»
✅ Ціна: «Цена»
✅ Код товару: «Код»
✅ Бренд: «Производитель»
▫️ Залишок: —
...
```

- Якщо щось не так — натисніть поле й оберіть потрібну колонку або
  «немає такої колонки».
- **«✅ Все правильно, далі»**.
- Якщо у файлі немає залишків, бот спитає, **за скільки днів** постачальник
  привозить товар. Усі товари будуть «під замовлення» з цим терміном.
- Бот спитає **націнку**. Якщо ціни у файлі вже для покупців — «без
  націнки». Якщо закупівельні — оберіть, скільки додати.
- Наприкінці напишіть **назву постачальника** у відповідь на повідомлення
  бота (наприклад, «Наша 1С» або «China Avto»).

Якщо постачальник змінив вигляд файлу (перейменував чи додав колонки), бот
вважатиме його новим і спитає ще раз. У кінці оберіть цього постачальника зі
списку («🔁 … змінив файл») — тоді його товари оновляться, а не задвояться.

## Звіт перед «Застосувати»

Бот спершу перевіряє файл і нічого не змінює. У звіті:

| Що бачите | Що робити |
|---|---|
| **Пропущено рядків** — з номером рядка і причиною | Подивіться ці рядки у файлі: немає назви, незрозуміла ціна. Решта завантажиться. |
| **Нових брендів** | Перевірте, чи це не описка в назві бренду. |
| **Авто, яких немає в довіднику** | Натисніть **«🚗 Зіставити авто»** під звітом: бот запропонує моделі, ви підтвердите кнопками. Потім надішліть файл ще раз. |
| **Не впізнав категорію** — пішли в «Інше» | Додайте слово з назви товару до категорії: `/word слово` (див. нижче). |
| **Буде: ➕ нових · ✏️ оновлено · 🚫 знято з продажу** | Якщо все так — **«✅ Застосувати»**. |

Товари, яких більше немає у файлі постачальника, знімаються з продажу. Якщо
так зникло б більше п'ятої частини його товарів, бот зупиниться й спитає:
так виглядає обірваний файл (один аркуш замість усіх). Якщо постачальник
справді прибрав ці товари — **«⚠️ Застосувати все одно»**.

## Категорії

Товар потрапляє в категорію, коли в його назві або в групі з 1С є одне зі
слів цієї категорії. Якщо підходить кілька слів, перемагає найдовше:
«фильтр масл» (масляний фільтр) важить більше, ніж «масл» (олива). Товари,
яких не впізнало жодне слово, йдуть в «Інше».

- **`/categories`** — усі розділи й підкатегорії з кнопками. Відкрийте
  категорію, щоб побачити її слова. Там можна:
  - 🔤 додати слово або ✖ прибрати його;
  - ➕ створити підкатегорію чи новий розділ, ✏️ перейменувати, 🗑 видалити.
- **`/word слово`** — швидкий шлях зі звіту: напишіть шматок назви
  нерозпізнаного товару (`/word вал распредел`) і оберіть категорію.

Перед кожною зміною бот показує, які товари куди переїдуть, і нічого не
змінює до «✅ Застосувати». Пишіть слово як шматок слова: `колодк`
підходить і до «колодки», і до «колодок».

## Постачальники

**`/suppliers`** — список постачальників. Для кожного видно, які колонки
бот бере з його файлу, і можна змінити націнку, термін доставки або видалити
постачальника. Якщо видалити, його товари лишаться в каталозі, а наступний
його файл бот спитає як новий.

## Довідник авто

Машини, яких немає в каталозі Auto-DB (наприклад, Chery, BYD), беруться з
довідника магазину. Його можна:

- доповнити з чату: `/car Peugeot 308 T7 2008-2013 1.6 HDi дизель`, або
  кнопкою «➕ Додати в довідник» під час зіставлення авто;
- завантажити файлом `.csv` з підписом **`авто`** — у форматі
  [data/vehicles.csv](../../data/vehicles.csv).

`/cars` — підтверджені відповідності назв авто постачальників моделям
довідника.

## Для розробника

- Приклади файлів: [example-price.csv](example-price.csv) (саме його
  імпортує інтеграційний тест) і [avtomir-demo.xlsx](avtomir-demo.xlsx).
- Постачальник, якого вже налаштовано в чаті, вантажиться й з командного
  рядка: `make import SUPPLIER="Наша 1С" FILE=price.xlsx DRY_RUN=1`.
- Стартове дерево категорій — [data/categories.csv](../../data/categories.csv).
  Воно заповнює лише порожню базу; далі дерево живе в базі й змінюється в
  чаті.
- Автоматичного обміну з 1С (стандарт CommerceML, «Обмін з сайтом») поки
  немає: товари надходять файлами. Він ляже на тих самих постачальників і
  категорії.
